About This SSC GK GS Practice Site

SSC GK GS Quiz & Preparation is a free practice site for the General Awareness paper of SSC CGL, CHSL, CPO and MTS. It exists to make one thing easy: answering GK and GS questions, checking the answer and reading a short explanation that fixes the fact in memory.

Who this is for

Aspirants preparing for SSC exams who want daily question practice without a login, an app install or a paid course. The content is also relevant to other competitive exams with a general awareness component, because the underlying syllabus overlaps heavily.

How the question bank is maintained

The site currently serves 23,654 multiple-choice questions across ten subjects. Each question carries four options, one correct answer and an explanation. The bank is kept as structured JSON files, one per subject, and is validated on every import: four options, a valid answer index, a non-empty explanation and no duplicate question text.

Questions are compiled from standard SSC preparation material and organised by topic. They are practice material, not official question papers, and SSC does not endorse this site. If you find an answer that you believe is wrong, or an explanation that is unclear, report it on the Telegram channel with the question text — corrections are applied to the bank and appear in the next update.

Adding your own questions (JSON import)

If you maintain your own question bank, you can import it. The format is a JSON array of questions, one file per subject, and a small script in the project validates the file and rejects duplicates before merging it into the bank.

[
  {
    "question": "Who is known as the Father of the Indian Constitution?",
    "options": ["Jawaharlal Nehru", "B. R. Ambedkar", "Rajendra Prasad", "Sardar Patel"],
    "correct_option": 1,
    "explanation": "Dr B. R. Ambedkar chaired the Drafting Committee of the Constituent Assembly."
  }
]

Full instructions, validation rules and the duplicate-checking workflow are on the question import guide.

Privacy and data

This is a static site. There is no account system, no cookie for tracking, no advertising network and no analytics script. Quiz answers stay in your browser's memory for the length of the session. The only outbound link that collects anything is the Telegram channel, which is governed by Telegram's own privacy policy.

Contact and corrections
