How to use these sets

Twenty questions take about five minutes. The value is in the explanation, so read it even when you answer correctly — most SSC GK questions are one fact away from a related question that appears in another shift. Keep a note of every question you get wrong and revise that note weekly.

If you are close to the exam, alternate between a subject set and an exam-style set. Subject sets build depth; mixed sets train the context switching that the actual paper demands.

Do the quizzes work offline?

Once a page and its question file are cached by your browser, the quiz can run without a fresh connection. On a first visit you need to be online to load the question file.

Are the questions the same every time?

No. Each set is shuffled and drawn at random from the selected pool, so a repeat visit usually gives a different set.
